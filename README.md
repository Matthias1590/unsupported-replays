# Unsupported VALORANT replays

Three replay samples for every available VALORANT build from 11.06 through 12.09, intended for implementing and validating older-build support in [vrfkit](https://github.com/yakisoba0728/vrfkit).

Builds: `11.06`, `11.07`, `11.08`, `11.09`, `11.10`, `11.11`, `12.00`, `12.01`, `12.02`, `12.03`, `12.04`, `12.05`, `12.06`, `12.07`, `12.08`, `12.09`

Replay binaries are stored with Git LFS. SHA-256 hashes are in `SHA256SUMS.txt`.
